## Описание проекта
Практическая реализация динамического веб-интерфейса с манипуляциями элементами DOM-дерева, переключением режимов отображения, поддержкой пользовательских тем оформления и отказоустойчивой обработкой событий в JavaScript.

---

## Реализованный функционал

1. **Динамическое добавление элементов:**
   * Интерактивное создание карточки хобби по кнопке «Добавить хобби» через ввод названия в `prompt()`.
   * Валидация пользовательского ввода: обработка отмены действия и защита от создания пустых записей.
   * Безопасная вставка текста через свойство `textContent` для предотвращения XSS-уязвимостей.
   * Генерация векторной заглушки (inline SVG) и присвоение обязательного селектора `hobby-item`.

2. **Переключение режимов отображения (Layout Switcher):**
   * Переключение между сеточным и строчным видом контейнера хобби (`view-grid` / `view-list`).
   * В соответствии с требованиями для `.view-grid .hobby-item` задан `display: flex`, а для `.view-list .hobby-item` — `display: block`.

3. **Скрытие и восстановление секции:**
   * Управление видимостью секции через утилитный класс `hidden` (`display: none !important;`).
   * Восстановление отображения секции при клике на соответствующий пункт меню («Хобби») в навигационной панели шапки.

4. **Тёмная тема (Dark Theme) и сохранение состояния:**
   * Переключение цветовой схемы через класс `dark-theme` на элементе `<body>`.
   * Использование кастомных CSS-переменных (`var(--...)`) для адаптации фона, текста, карточек мест и виджета погоды.
   * Запись выбранного состояния в `localStorage` для сохранения темы при перезагрузке страницы.

5. **Отказоустойчивость и обработка ошибок (Defensive Programming):**
   * Проверка наличия всех ключевых селекторов и DOM-элементов перед навешиванием обработчиков событий.
   * Информативное логирование этапов работы и потенциальных сбоев в консоль браузера (`console.error`, `console.warn`, `console.log`).

## Валидация и соответствие стандартам

Все исходные файлы проекта прошли полное тестирование и валидацию:

* **HTML (`index.html`):** Полностью соответствует стандарту W3C HTML5. Все структурные блоки `<article>` снабжены идентифицирующими заголовками, предупреждения валидатора устранены[cite: 9].
* **CSS (`style.css`):** Успешно прошёл валидацию W3C CSS. Свойства позиционирования, CSS-переменные, медиазапросы и состояния фокуса (`outline`, `outline-offset: 2px`) настроены без синтаксических ошибок[cite: 4].
* **JavaScript (`script.js`):** Написан по стандартам ES6+, код валиден, не содержит синтаксических ошибок, исключений времени выполнения и сбоев доступа к `null / undefined`.
